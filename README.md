# Weather App

A modern, clean Android Weather Application that provides real-time weather information using the OpenWeatherMap API.

## Features
- **Current Weather:** Get real-time temperature, humidity, and wind speed.
- **City Search:** Search for weather data in any city worldwide.
- **Material Design:** Clean UI with Material Design components and card-based layout.
- **Dynamic Icons:** High-quality weather condition icons.
- **Turkish/English Support:** The app has been localized for English speakers.

## Technologies Used
- **Language:** Java
- **Networking:** [Retrofit 2](https://square.github.io/retrofit/)
- **JSON Parsing:** [Gson](https://github.com/google/gson)
- **Image Loading:** [Glide](https://github.com/bumptech/glide)
- **UI:** Material Design, ConstraintLayout, Gradient Backgrounds.

## Setup
1. Clone the repository.
2. Open the project in Android Studio.
3. Replace the `API_KEY` in `WeatherActivity.java` with your own key from [OpenWeatherMap](https://openweathermap.org/api).
4. Build and run the project.
